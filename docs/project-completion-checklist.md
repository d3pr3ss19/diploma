# План до полного завершения проекта

## 0) Блокер прямо сейчас: Prisma DB authentication

Ошибка:

`PrismaClientInitializationError: Authentication failed against database server at localhost`

Что сделать:

1. Проверить `backend/.env` и значение `DATABASE_URL`.
2. Убедиться, что PostgreSQL запущен и доступен.
3. Проверить логин/пароль пользователя БД (вручную через `psql`).
4. После исправления credentials выполнить:
   - `npm run prisma:generate`
   - `npm run prisma:migrate:deploy` (или `prisma db push` для локального dev-старта)
5. Перезапустить backend и проверить `GET /api/v1/health`.
